# Configuration

[[← Installation|EN-Installation]] · [[Weather →|EN-Weather]]

Configure MeteoMatrix from the Berry script settings in your AWTRIX NG web interface.

| Setting | Meaning | Example |
| --- | --- | --- |
| `latitude` | Decimal latitude | `51.590748` |
| `longitude` | Decimal longitude | `18.736974` |
| `timezone` | IANA timezone | `Europe/Warsaw` |
| `language` | Display label language | `en` or `pl` |

The sample coordinates correspond to **Sieradz, Poland**. Replace them with your desired location.

Use decimal points for coordinates and a named IANA timezone for correct local event times. Open-Meteo availability may differ by region, especially for pollen data.
