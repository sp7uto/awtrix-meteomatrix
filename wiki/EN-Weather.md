# Weather data

[[← Configuration|EN-Configuration]] · [[Air quality →|EN-Air-quality-and-pollen]]

MeteoMatrix presents weather values alongside original 8×8 pixel-art illustrations.

| Measurement | Meaning |
| --- | --- |
| Temperature | Current air temperature |
| Feels-like temperature | Apparent temperature |
| Precipitation | Rainfall/precipitation amount |
| Snowfall | Snow measurement |
| Wind | Wind conditions |
| Cloud cover | Proportion of cloudy sky |
| Pressure | Atmospheric pressure |

## Zero-value display

Selected measurements with a value of **0.0** are hidden to keep screens readable. **Temperature is displayed even when it is zero.**

Weather information is supplied by Open-Meteo.
