# Dane pogodowe

[[← Konfiguracja|PL-Konfiguracja]] · [[Jakość powietrza →|PL-Jakosc-powietrza-i-pylki]]

MeteoMatrix prezentuje informacje pogodowe na wyświetlaczu LED 32 × 8, łącząc czytelne wartości z ikonami pikselowymi.

| Parametr | Co przedstawia |
| --- | --- |
| Temperatura | Aktualna temperatura powietrza |
| Temperatura odczuwalna | Temperatura uwzględniająca wpływ warunków otoczenia |
| Opady | Ilość opadów |
| Śnieg | Opady śniegu |
| Wiatr | Parametry wiatru |
| Zachmurzenie | Udział nieba przykrytego chmurami |
| Ciśnienie | Ciśnienie atmosferyczne |

## Czytelność

Zgodnie z przyjętym projektem wybrane wartości **0,0** są pomijane, by nie zajmować miejsca na ekranie. **Temperatura pozostaje widoczna również przy wartości zero.**

Ikony mają oryginalną stylistykę 8 × 8 pikseli, wywodzącą się z SieradzMeteo v1.6.
